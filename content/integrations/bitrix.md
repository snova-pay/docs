# Модуль для 1С-Битрикс

Принимайте оплату на интернет-магазине под управлением **1С-Битрикс: Управление сайтом**.

## Инструкция по подключению

:::steps
### Скачайте модуль интеграции

Скачайте архив платежного модуля из репозитория GitHub или из маркетплейса Битрикс:
[Репозиторий модуля Snova Pay для 1С-Битрикс](https://github.com/Snova-Pay/bitrix-payment-module).

### Установите через административную панель

Перейдите в **Рабочий стол -> Marketplace -> Установленные решения** и загрузите архив. Нажмите **Установить**.

### Настройте платёжную систему

1. В меню выберите **Магазин -> Настройки -> Платежные системы**
2. Добавьте новую платёжную систему, выбрав обработчик **Snova Pay (snova.pay)**
3. Заполните параметры магазина: `SHOP_ID`, `SECRET_KEY`, `WEBHOOK_URL`
4. Сохраните изменения
:::
