# 1С-Битрикс

Модуль **«SNOVA — подписки»** (`snova.subscriptions`) для 1С-Битрикс: Управление сайтом. Он показывает виджет подписки на карточке товара и создаёт в модуле «Интернет-магазин» оплаченный заказ на каждое списание по подписке.

:::callout{type="info"}
Модуль не является платёжной системой Битрикса. Подписку покупатель оплачивает на платёжной странице вашего провайдера (ЮKassa или CloudPayments), подключённого в личном кабинете SNOVA. Модуль только принимает уже оплаченные заказы.
:::

## Требования

* Редакция с модулем «Интернет-магазин» (`sale`): без него модуль не установится.
* Подключённый эквайринг в [личном кабинете SNOVA](https://dashboard.snova-pay.ru/): **Настройки → Эквайринг**.

## Как это работает

1. Каталог Битрикса передаётся в SNOVA. Внешний ID товара в SNOVA — это ID элемента или торгового предложения в Битриксе.
2. Модуль выводит виджет на карточке товара. Покупатель оформляет подписку и оплачивает её в виджете.
3. После каждого успешного списания SNOVA отправляет вебхук `order.paid`. Модуль запрашивает у SNOVA детали заказа, создаёт оплаченный заказ в Битриксе и сообщает SNOVA его номер.
4. Покупатель управляет подпиской в портале SNOVA.

## Установка

:::steps
### Установите модуль

1. Получите архив модуля и убедитесь, что при распаковке в `/bitrix/modules/` получается путь `/bitrix/modules/snova.subscriptions/…`.
2. В админке откройте **Маркетплейс → Установленные решения → «Установить решение из файла»** и загрузите архив.
3. В списке **Маркетплейс → Установленные решения** найдите «SNOVA — подписки» и нажмите **«Установить»**.

### Подготовьте сущности в Битриксе

Модуль не создаёт их сам:

1. **Платёжная система** «SNOVA (подписка)»: **Магазин → Настройки → Платёжные системы → Добавить**. Обработчик — любой ручной, например «Оплата при получении»: заказы приходят уже оплаченными.
2. **Служба доставки** (**Магазин → Настройки → Доставка**) — та, которой вы отправляете заказы подписок.
3. **Свойство заказа для ID заказа SNOVA** (**Магазин → Настройки → Свойства заказов**): тип «Строка», не обязательное для покупателя. По нему модуль не создаёт дубли заказов.
4. По желанию — свойства для ФИО, телефона и адреса доставки, чтобы данные покупателя попадали в стандартные поля заказа.
5. По желанию — свойства для **ID подписки SNOVA** и **ссылки на подписку**.
6. Если сделали пункт 5 — служебное свойство **«флаг синхронизации отмены»** (тип «Строка», не показывать покупателю). Без него отмена заказа не отменит подписку.

### Выпустите ключи в SNOVA

В личном кабинете SNOVA откройте **API → API-ключи** и выпустите ключ с назначением **«Интеграция с CMS»**. Секретный ключ показывается один раз. В блоке **«Уведомления на ваш сервер»** нажмите **«Сгенерировать секрет»** и скопируйте его.

### Заполните настройки модуля

Откройте **Настройки → Настройки продукта → Настройки модулей → SNOVA — подписки**:

| Поле | Что указать |
| :--- | :--- |
| Адрес API SNOVA | Оставьте по умолчанию |
| Публичный и секретный ключ | Ключи с назначением «Интеграция с CMS» |
| Секрет для проверки вебхуков | Секрет из блока «Уведомления на ваш сервер» |
| Адрес личного кабинета SNOVA | Оставьте по умолчанию. Нужен для ссылки на подписку в заказе |
| Платёжная система, служба доставки | Созданные на предыдущем шаге |
| Код свойства заказа для ID SNOVA | Код свойства из пункта 3 |
| Коды свойств подписки и флага отмены | Коды из пунктов 5–6, если создавали |
| Автовставка виджета | Включите, если у вас стандартные шаблоны каталога (см. ниже) |
| Адрес скрипта виджета | Оставьте по умолчанию |
| Тема виджета | Пять полей цвета; пустые поля оставляют тему по умолчанию |

### Укажите адрес вебхука в SNOVA

При установке модуль кладёт в корень сайта файл обработчика. В личном кабинете SNOVA, в разделе **API → Уведомления на ваш сервер**, укажите адрес:

```text
https://ваш-сайт.ru/snova_subscriptions_webhook.php
```

### Передайте каталог в SNOVA

Внешние ID товаров в SNOVA должны совпадать с ID элементов и торговых предложений Битрикса. Выгрузите каталог в формате YML (**Магазин → Настройки → Экспорт данных**, профиль Яндекс.Маркета) и подключите ссылку на выгрузку в разделе **Каталог и планы** личного кабинета SNOVA. Другой способ — отправлять товары методом [`POST /v1/api/catalog/sync`](/api-reference).

### Создайте планы подписки

В разделе **Каталог и планы** создайте планы и выберите товары, к которым они применяются.
:::

## Вставка виджета на карточку товара

Режимы можно использовать одновременно.

### Автоматическая вставка

Включите **«Автовставка виджета»** в настройках модуля. Модуль находит на странице микроразметку schema.org (`<meta itemprop="sku" …>`), которую выводят стандартные шаблоны каталога Битрикса, и вставляет виджет сам. Подходит для товаров без торговых предложений.

### Точная вставка в шаблон

Надёжный способ для любых товаров, в том числе с торговыми предложениями. Добавьте в шаблон компонента `bitrix:catalog.element`:

```php
<?php $snovaThemeStyle = \Snova\Subscriptions\Settings::widgetThemeStyle(); ?>
<script src="<?= htmlspecialcharsbx(\Snova\Subscriptions\Settings::widgetScriptUrl()) ?>" defer></script>
<snova-widget
    <?= $snovaThemeStyle !== '' ? 'style="' . htmlspecialcharsbx($snovaThemeStyle) . '"' : '' ?>
    apikey="<?= htmlspecialcharsbx(\Snova\Subscriptions\Settings::apiPublicKey()) ?>"
    externalproductid="<?= (int)$arResult['ID'] ?>"
    externalvariantid="<?= (int)($arResult['OFFERS'][0]['ID'] ?? $arResult['ID']) ?>"
    price="<?= (float)($arResult['ITEM_PRICES'][0]['PRICE'] ?? $arResult['CATALOG_PRICE_1']) ?>"
></snova-widget>
```

Ключи `$arResult` зависят от вашего шаблона: сверьте их со структурой результата компонента на своём сайте.

:::callout{type="warning"}
Не пропускайте тег `<script>`: без него браузер не знает тег `<snova-widget>` и ничего не покажет.
:::

## Возвраты и отмена

* **Возврат в SNOVA → Битрикс.** Полный возврат отменяет заказ в Битриксе и снимает отметку об оплате. Частичный возврат автоматически не отражается: в Битриксе нет модели частично возвращённого заказа. Событие записывается в журнал.
* **Отмена заказа в Битриксе → SNOVA.** Если заполнены свойства «ID подписки SNOVA» и «флаг синхронизации отмены», то отмена заказа (поле «Отменён» = «Да») отменяет подписку в SNOVA.

## Проверка после установки

1. Откройте в браузере `https://ваш-сайт.ru/snova_subscriptions_webhook.php`. Должен вернуться ответ `{"ok":true}`. Если получили 403 или 404, переустановите модуль или скопируйте файл `bitrix/modules/snova.subscriptions/install/public/snova_subscriptions_webhook.php` в корень сайта вручную.
2. Оформите тестовую подписку через виджет. Удобнее всего с ключами тестового магазина ЮKassa (`test_…`).
3. Проверьте, что в Битриксе появился оплаченный заказ с правильными позициями, а в журнале доставок SNOVA (**API → Журнал доставок**) событие получило статус «Доставлен».

## Ограничения

* Частичные возвраты не отражаются в заказе Битрикса автоматически, только полные.
* Автовставка работает для простых товаров. Для товаров с торговыми предложениями используйте точную вставку.
* Синхронизация отмены реагирует только на изменение поля «Отменён». Полное удаление заказа подписку не отменяет.
