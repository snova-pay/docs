# inSales

Приложение **«SNOVA — подписки»** подключает подписки к магазину на inSales. Приложение само синхронизирует каталог, ставит виджет на страницы товаров, создаёт в магазине заказы на каждую оплаченную поставку и добавляет способ оплаты «Подписка SNOVA» в корзину.

Код в тему магазина вставлять не нужно: всё, что требуется на витрине, приложение создаёт через API магазина.

## Что делает приложение

| Возможность | Как работает |
| :--- | :--- |
| Каталог | Товары и варианты магазина попадают в каталог SNOVA. Архивные и скрытые товары помечаются «нет в наличии» |
| Виджет на карточке | Встаёт под блоком покупки (тема «Base»). Виджет находит товар по адресу страницы и учитывает выбранный вариант |
| Заказы | Каждое успешное списание создаёт заказ в inSales, сразу помеченный оплаченным. Раз в час приложение досоздаёт заказы, которые не пришли через вебхук |
| Оплата подпиской в корзине | Способ оплаты «Подписка SNOVA»: покупатель для каждой позиции выбирает разовую покупку или план и платит один раз за весь заказ |
| Возвраты | Возврат в SNOVA переводит заказ магазина в статус «Возврат». Отмена или возврат заказа в магазине по желанию возвращает деньги через SNOVA |

Планы, подписки, письма покупателям и портал покупателя остаются в SNOVA.

## Подключение

:::steps
### Выпустите ключ в SNOVA

В [личном кабинете SNOVA](https://dashboard.snova-pay.ru/) откройте **API → API-ключи**, выберите назначение **«Интеграция с CMS»** и нажмите **«Выпустить ключ»**. Сохраните публичный и секретный ключи: секретный показывается один раз.

### Установите приложение

В админке inSales установите приложение **«SNOVA — подписки»** и откройте его. Вход в приложение идёт через inSales, отдельный пароль не нужен.

### Подключите магазин

Вставьте публичный и секретный ключи и нажмите **«Подключить магазин»**. Приложение не хранит секретный ключ: он нужен один раз, чтобы подтвердить, что это ваш аккаунт SNOVA.

При подключении приложение само:

* ставит скрипт виджета на витрину;
* подписывается на изменения товаров;
* прописывает в SNOVA адрес для вебхуков и создаёт секрет, если его ещё нет;
* синхронизирует каталог.

### Выберите оплату и доставку для заказов подписок

Укажите **способ оплаты** и **способ доставки**, с которыми приложение будет создавать заказы подписок, и сохраните.

:::callout{type="warning"}
Выберите способ оплаты, который не пробивает чек повторно. Чек по каждому списанию уже пробил ваш платёжный провайдер (54-ФЗ).
:::

### Создайте планы и включите товары

В кабинете SNOVA, в разделе **Каталог и планы**, создайте планы подписки. Затем в таблице товаров приложения отметьте:

* **«По подписке»** — без этой отметки виджета на странице товара нет;
* **«Только по подписке»** — скрывает стандартный блок покупки магазина и вариант «Разовая покупка» в виджете.
:::

:::callout{type="info"}
К одному аккаунту SNOVA подключается один магазин: у аккаунта один адрес вебхуков. Если в SNOVA уже указан другой адрес (например, от плагина WooCommerce), подключение не выполнится и ничего не перезапишет.
:::

## Оформление на странице товара

Покупатель выбирает план, вводит email, отмечает согласия и нажимает **«Продолжить»**. На втором шаге «Данные для доставки» он указывает имя, телефон, адрес и город: без телефона inSales не создаст заказ. После оплаты первой поставки в магазине появляется оплаченный заказ.

Место виджета можно изменить в личном кабинете SNOVA: раздел **Установка виджета → Место виджета на странице**, кнопка **«Выбрать место»**.

## Оплата подпиской в корзине

Включается кнопкой на странице настроек приложения: она создаёт в магазине внешний способ оплаты «Подписка SNOVA».

1. На последнем шаге оформления покупатель выбирает «Подписка SNOVA».
2. На странице выбора для каждой позиции показываются разовая покупка и подходящие планы с ценой со скидкой. Покупатель указывает email и отмечает согласия.
3. SNOVA списывает весь заказ одним платежом: разовые позиции, позиции на подписке и доставку. Доставку в продлениях задаёт настройка приложения: бесплатно, как в первом заказе или фиксированная сумма.
4. Покупатель возвращается на страницу успешной оплаты магазина, заказ inSales помечается оплаченным.

Если сумма со скидкой плана отличается от суммы заказа inSales, приложение подтверждает сумму заказа магазина, а фактически списанную сумму записывает комментарием в заказ.

:::callout{type="warning"}
Внешние способы оплаты недоступны на тарифе inSales «Комбо». Подписка со страницы товара работает на любом тарифе.
:::

## Возвраты

* **Из SNOVA в магазин.** Возврат, сделанный в SNOVA, переводит заказ магазина в статус «Возврат», снимает отметку об оплате и добавляет сумму возврата в комментарий.
* **Из магазина в SNOVA.** Если в настройках приложения включены возвраты из магазина, перевод заказа в «Отменён» или «Возврат» возвращает деньги покупателю через SNOVA.

## «Мои подписки» на витрине

Приложение добавляет в шапку витрины ссылку «Мои подписки». Она открывает портал покупателя SNOVA, где покупатель входит по ссылке из письма на свой email.

## Кнопки на странице настроек

| Кнопка | Что делает |
| :--- | :--- |
| Обновить каталог | Повторно синхронизирует товары и варианты |
| Проверить пропущенные заказы | Создаёт в магазине заказы по оплатам, которые не пришли через вебхук |
| Переустановить скрипт витрины | Восстанавливает скрипт виджета, если его удалили |
| Отключить магазин | Отключает магазин от SNOVA |

## Ограничения

* Со страницы товара оформляется одна позиция по плану. Доставка в продлениях настраивается только для оплаты подпиской в корзине.
* Ссылка «Мои подписки» ведёт на вход в портал по email: inSales не передаёт витрине данные вошедшего покупателя, поэтому мгновенного входа без письма нет.
* Подписками покупатель управляет в портале SNOVA, а не в личном кабинете inSales.
