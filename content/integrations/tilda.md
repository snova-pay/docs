# Tilda

Интеграция с Tilda добавляет виджет подписки на страницы товаров вашего магазина на Tilda и подписку на всю корзину. Каталог SNOVA берёт из YML-выгрузки Tilda, а виджет подключается одним кодом в HEAD сайта.

:::callout{type="info"}
Приём оплаты в настройках Tilda («Платёжные системы») подключать не нужно. Подписку покупатель оплачивает на платёжной странице вашего провайдера (ЮKassa или CloudPayments), подключённого в личном кабинете SNOVA.
:::

## Перед началом

* В [личном кабинете SNOVA](https://dashboard.snova-pay.ru/) подключён эквайринг: **Настройки → Эквайринг** (см. [Начало работы](/quickstart)).
* Товары в Tilda оформлены через каталог товаров Tilda (Tilda Store), и у каталога есть YML-выгрузка.

## Подключение

:::steps
### Подключите каталог из Tilda

В личном кабинете SNOVA откройте **Каталог и планы → Каталог из Тильды → Настроить**. Вставьте ссылку на YML-выгрузку каталога (вида `https://ваш-сайт.tilda.ws/tstore/yml/…`) и сохраните. Нажмите **«Обновить»**: товары, варианты и адреса их страниц появятся в SNOVA.

Чтобы каталог обновлялся сам, включите **«Обновлять каталог автоматически раз в 12 часов»**. По умолчанию автообновление выключено, а кнопка «Обновить» работает всегда.

### Создайте планы подписки

В том же разделе создайте планы: периодичность, скидку и товары, к которым план применяется.

### Вставьте код на сайт

Откройте раздел **Установка виджета**, блок **«Подключение к Тильде»**, и скопируйте код. Он выглядит так:

```html
<script defer src="https://widget.snova-pay.ru/snova-widget-tilda.js" data-snova-tilda-key="pk_..."></script>
```

В Tilda откройте **Настройки сайта → Вставка кода → HTML-код для HEAD**, вставьте код и сохраните.

### Опубликуйте сайт

Нажмите **«Опубликовать все страницы»**. Tilda добавляет код из HEAD в страницы только при публикации: без неё на уже опубликованных страницах товаров виджета не будет.

### Проверьте установку

В разделе **Установка виджета** нажмите **«Проверить»** в блоке проверки установки. SNOVA откроет главную и страницы товаров вашего сайта и покажет статус каждой:

| Статус | Что делать |
| :--- | :--- |
| Установлено | Всё в порядке |
| Скрипта нет | Код не добавлен в HEAD или страницы не переопубликованы |
| Чужой ключ | На странице код с другим ключом — вставьте код из своего кабинета |
| Страница не открылась | Проверьте, что страница опубликована и открывается без пароля |
:::

Страницы товаров привязывать вручную не нужно: виджет находит товар по адресу страницы из YML-выгрузки. Изменения настроек в кабинете доходят до сайта примерно за 1–5 минут.

## Где появляется виджет

Место выбирается в таком порядке:

1. **Явный слот.** Если на странице есть элемент `<div data-snova-tilda-slot></div>` (например, в HTML-блоке шаблона карточки товара), виджет встанет в него.
2. **Место, выбранное в кабинете.** В разделе **Установка виджета → Место виджета на странице** вставьте ссылку на страницу товара и нажмите **«Выбрать место»**. Откроется ваш сайт: кликните элемент (например, кнопку «Купить») и выберите **«Перед элементом»** или **«После элемента»**. Выбор применяется ко всем товарам с тем же шаблоном. После выбора проверьте 1–2 других товара.
3. **Плавающая панель.** Если ни слота, ни выбранного места нет, виджет показывается в отдельной плавающей панели.

## Варианты товара

Если у товара есть варианты (вес, размер), виджет следит за выбором покупателя в карточке Tilda и пересчитывает цену и скидку для выбранного варианта. Учитываются только варианты, которые есть в YML-выгрузке.

## Подписка на корзину

Пока в корзине Tilda есть товары из каталога SNOVA, внутри корзины, над кнопкой «Оформить заказ», появляется предложение оформить их подпиской. Покупатель выбирает план, общий для всех позиций, и платит сумму позиций со скидкой плана.

* Товары, которых нет в каталоге SNOVA, в подписку не входят: покупатель оформляет их обычным способом. Над карточкой подписки показывается, сколько таких товаров.
* Для всей корзины действует один план.
* После оформления подписки Tilda сама не убирает эти товары из корзины: покупатель удаляет их вручную, если хочет купить остальное обычным способом.
* Отключить подписку на корзину или выбрать для неё другое место можно в разделе **Установка виджета** («Место подписки в корзине»).

## Анкета покупателя

Если перед оплатой вам нужны дополнительные данные (имя, телефон, адрес доставки, удобное время), соберите анкету в разделе **Установка виджета → Анкета для покупателя**. Доступные поля: строка, многострочный текст, число, телефон, дата, галочка, выпадающий список и выбор одного варианта кнопками. Любое поле можно сделать обязательным.

С анкетой виджет работает в два шага: план, email и согласия → «Продолжить» → анкета и оплата. Ответы покупателя видны в карточке подписки в кабинете. Анкету можно менять без правки кода на сайте.

## Ссылка «Мои подписки»

Добавьте в меню сайта пункт «Мои подписки» со ссылкой `#snova-account`. Клик по нему откроет портал покупателя SNOVA в новой вкладке. Вместо ссылки можно добавить атрибут `data-snova-account` любому элементу.

## Тестовая покупка

Подключите в кабинете ключи тестового магазина ЮKassa (`test_…`), оформите подписку на своём сайте тестовой картой ЮKassa и проверьте, что подписка появилась в разделе **Подписки**. Перед запуском замените ключи на боевые.

## Для разработчиков

Адаптер отправляет события на `document`, которые удобно использовать для отладки:

| Событие | Когда |
| :--- | :--- |
| `snova:tilda:mounted` | Виджет встал на страницу |
| `snova:tilda:unmatched` | Адреса страницы нет в каталоге |
| `snova:tilda:missing-slot` | Место для виджета не найдено |
| `snova:tilda:invalid-config` | Не удалось загрузить настройки |

События не содержат персональных данных покупателя.
